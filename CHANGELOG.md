First versioned reference release for the SysAdminDoc fork.

- Rewrote the README around package lookup, offline downloads and the fork's dataset snapshot.
- Made removal classifications and missing research explicit. The underlying 5,481 package records and 47 suggestion lists are unchanged.
- Refreshed the existing reference browser with readable risk labels, category navigation and replacement details.
- Repaired the mdBook build configuration, replaced the no-op test script and added checked offline packaging.
- Prevented three capitalization-only ID pairs from overwriting each other's pages on Windows. The package identifiers themselves are unchanged.
- Preserved the original source and all captured browser reviews.

The dataset itself was last changed on 2026-05-14. This version is a presentation and packaging release, not a fresh device-safety review.
