# Android Debloat List v0.1.0

Open `reference/index.html` to browse this snapshot. Use a browser with JavaScript enabled for search. You don't need PHP, Python or mdBook to read the reference.

- `reference/` contains the complete static browser.
- `data/` contains the original JSON lists, suggestion categories and schemas.
- `source/` contains the source and build instructions for this edition.
- `LICENSE` is the AGPL-3.0-or-later license retained from upstream.
- `THIRD-PARTY-NOTICES.txt` covers the reference renderer and its bundled assets.
- `manifest.json` lists each included file's size and SHA-256 hash.

This is a reference, not an installer or device-management application. The data was last changed in this fork on 2026-05-14. No package-removal recommendation was revalidated for this presentation release.

Search by exact ID. Read the recorded notes and warnings before you consider changing a device. External references and the App Manager link open another website or application only when followed.
